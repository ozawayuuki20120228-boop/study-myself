鴻鵠 2.0 - PWA版

【内容】
- 黒背景・白文字のシンプルな画面
- ToDo（予定日、完了/未完了、履歴）
- カレンダー（日付別ToDo・学習記録・メモ）
- 学習タイマー（開始時刻を保存し、画面を閉じている間も経過時間を再計算）
- 参考書ライブラリ（100冊以上の候補、検索、科目フィルター）
- 参考書詳細（ページ/語/問の進捗、単元、問題、理解度、周回、目標日、メモ）
- 学習分析
- JSONバックアップ書き出し
- オフライン用Service Worker

【Galaxyへのインストール】
1. ZIPを解凍する。
2. 解凍したフォルダの中身（index.html, style.css, app.js, manifest.webmanifest, sw.js, icon.svg）を、HTTPS対応のWebホスティングへアップロードする。
3. 発行されたHTTPS URLをGalaxyのChromeで開く。
4. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選ぶ。

【注意】
- PWAとして利用するにはHTTPS配信が必要です（localhostを除く）。
- 学習データはこの端末・このブラウザのlocalStorageに保存されます。ブラウザデータ削除や別端末への移行に備え、定期的に「⇧」からJSONバックアップを保存してください。
- この初版のデータベースは参考書タイトル候補です。出版社・版・ページ数・各書籍の全問題構成を公式に照合したものではありません。ページ数や問題番号は利用者が書籍に合わせて登録してください。
- 書影は実際の公式商品画像ではなく、書籍名を整えて表示するシンプルなデジタルカタログ表示です。公式書影の自動取得機能は含みません。
- タイマーは保存された開始時刻から経過時間を復元します。ブラウザ/OSの制限により、通知や厳密なバックグラウンド処理を保証するものではありません。
- このアプリは端末間同期やクラウドバックアップには対応していません。
